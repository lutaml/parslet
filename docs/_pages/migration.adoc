= Migration from Vanilla Parslet

Plurimath-parslet is a drop-in replacement for parslet 2.0.0 with 100% backward compatibility.

== Quick Migration

Simply replace in your Gemfile:

[source,ruby]
----
# Before
gem 'parslet', '~> 2.0'

# After
gem 'plurimath-parslet', '~> 3.1'
----

Run `bundle update parslet` and you're done!

== What Changes

**Nothing in your code** - All APIs are identical

**Better performance** - 59% faster on average

**Same behavior** - All parslet 2.0.0 tests pass
