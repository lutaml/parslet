== Plurimath Parslet: High-Performance PEG Parser for Ruby

image:https://github.com/plurimath/plurimath-parslet/workflows/rake/badge.svg["Build Status", link="https://github.com/plurimath/plurimath-parslet/actions?workflow=rake"]
image:https://img.shields.io/gem/v/plurimath-parslet.svg["Gem Version", link="https://rubygems.org/gems/plurimath-parslet"]

Plurimath Parslet is an optimized fork of the popular parslet gem, providing a high-performance PEG (Parsing Expression Grammar) parser construction library for Ruby with great error reporting and Opal (JavaScript) compatibility.

== Key features

* **59% faster on average** - Comprehensive optimizations for real-world performance
* **100% backward compatible** - Drop-in replacement for parslet 2.0.0
* **Automatic optimization** - Grammar AST optimizations applied transparently
* **Memory efficient** - 34-47% fewer allocations in typical workloads
* **Opal compatible** - Works in JavaScript environments via Opal
* **Excellent error reporting** - Detailed parse failure messages with context
* **Production proven** - Powers Plurimath's mathematical notation parsing

== Quick example

[source,ruby]
----
require 'parslet'

class SimpleParser < Parslet::Parser
  rule(:space)  { match('\s').repeat(1) }
  rule(:space?) { space.maybe }
  
  rule(:word)     { match('[a-z]').repeat(1) }
  rule(:sentence) { word >> (space >> word).repeat >> str('.') }
  
  root(:sentence)
end

parser = SimpleParser.new
result = parser.parse('hello world.')
# => {word: "hello"@0, word: "world"@6}
----

== What's optimized?

The optimization work includes:

**Grammar AST optimizations**::
* String sequence merging for faster string matching
* Quantifier simplification (e.g., `repeat(1,1)` → simple atom)
* Choice deduplication and reordering
* Lookahead simplification
* Empty alternative elimination

**Runtime optimizations**::
* Optimized string literal matching
* Efficient regex compilation and caching
* Improved position tracking
* Better error message generation

See link:_pages/optimizations[detailed optimization documentation] for complete information.

== Why plurimath-parslet?

**Production ready**:: Used in Plurimath to parse complex mathematical notation formats (AsciiMath, MathML, LaTeX, UnicodeMath).

**Thoroughly tested**:: 675/675 tests passing, including all vanilla parslet tests plus optimization-specific tests.

**Fair benchmarks**:: Rigorous methodology with identical measurement conditions proves 100% improvement rate with zero regressions.

**Excellent architecture**:: Clean visitor pattern for optimizations, maintaining separation of concerns and extensibility.

**Transparent optimizations**:: Optimizations are applied automatically during grammar compilation - no code changes needed.
