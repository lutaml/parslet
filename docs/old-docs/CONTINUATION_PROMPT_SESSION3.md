## Key Principles

Remember to follow these principles:

- **MECE**: Tests should be mutually exclusive, collectively exhaustive
- **Architecture First**: Test behavior, not implementation details
- **Separation of Concerns**: Benchmark infrastructure separate from tests
- **Extensibility**: Easy to add new test cases
- **Fast Execution**: Tests should complete quickly for CI
- **Clear Failures**: Error messages should guide fixes
